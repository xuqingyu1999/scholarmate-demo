# ScholarMate Project Map

- Static HTML/CSS/JS prototype with browser `localStorage` state.
- Shared business policies live in `scripts/business-core.js`.
- Shared page utilities, user state, seed patents/inventors, and legacy chat history live in `scripts/main.js`.
- Browser semantic recommendation lives in `scripts/semantic-search.js`.
- Third-round chat sessions and LLM demo client live in `scripts/chat-sessions.js` and `scripts/llm-client.js`.
