# ScholarMate 可用性审计与外部试用文档

## Goal

面向外部试用前做一次轻量可用性清扫：页面上不应出现明显按钮/链接但点击没有反应的控件；同时产出一份给非开发人员也能看懂的使用说明、功能说明和商业流程文档。

## Acceptance Criteria

- 静态页面中的主要 `<button>`、导航链接和业务 CTA 要么有明确动作，要么改成非按钮/禁用状态/清晰提示。
- 专利列表、用户中心、会员页、聊天页、专利详情页关键按钮能通过浏览器 smoke 点击或打开。
- 文档说明当前是静态前端原型，说明如何本地运行、如何分享给别人、有哪些可选部署方式。
- 文档覆盖主业务流程：企业注册认证、会员服务包、需求文本/需求项目、推荐、数字顾问、资料/对话许可、交易意向。
- 文档明确当前限制：无真实后端、无真实支付、无真实合同、LLM Key 只用于本机演示、localStorage 保存状态。

## Test Plan

- 用脚本扫描 HTML 中缺少动作的按钮、空 href 或 `href="#"` 链接。
- 用 Playwright 打开主要页面并点击关键控件，检查导航/弹窗/状态更新。
- 跑现有 Node 测试，确保业务核心、推荐、移动预览、聊天默认回复不回归。
