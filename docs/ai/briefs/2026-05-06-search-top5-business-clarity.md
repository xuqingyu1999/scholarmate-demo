# ScholarMate 搜索 Top 5 与业务清晰度评审

## Summary
- 搜索推荐页不再展示不可用分页，搜索后只展示最相关 Top 5。
- 页面文案保持精简，把“数字人资产/数字人席位”在核心入口调整为更像企业采购语言的“数字顾问/顾问席位”。
- 业务逻辑当前已经形成闭环，但企业用户仍需要一句话理解：会员买的是需求项目服务能力，顾问席位买的是持续咨询入口，资料/对话许可买的是某个付费专利的深聊权限。

## Acceptance Criteria
- 搜索结果页没有底部假分页。
- 自然语言搜索只显示 Top 5 推荐，结果数文案说明 Top 5 与总相关数。
- 用户中心和聊天页关键入口使用“数字顾问/顾问席位”，降低“资产”一词带来的抽象感。
- 不新增复杂页面，不增加额外弹窗，不打断当前需求-推荐-对话-交易意向主链路。

## Simulated Enterprise User Feedback
身份：制造业技术负责人，正在寻找“电池高温安全和热失控”相关技术。

使用感受：
- 我能理解平台主路径：先认证企业，再发布技术需求，看推荐专利，然后找数字顾问判断能不能落地。
- 会员比之前清楚一些，但“数字人会员”这个说法容易让我误会成买一个虚拟形象。改成“顾问席位”后，我更容易理解这是长期保留几个专家/专利顾问的咨询入口。
- 资料/对话许可比较合理，我会把它理解成某个付费专利的深度资料和深聊权限，不会误以为已经买了完整专利授权。
- 搜索页如果只给 Top 5，我更愿意逐个点进去看；底部分页不能用时会让我怀疑系统没有做完。

主要疑问：
- 免费共享专利、付费专利许可、会员顾问席位之间的关系还可以再短一点说清楚。
- 交易意向提交后谁跟进、什么时候跟进，后续可以在用户中心给一个更明确的状态。

## Business Process Expert Proposal
判断：当前业务逻辑已经基本清晰，闭环是“企业认证 -> 购买会员服务能力 -> 发布技术需求 -> 获得推荐 -> 使用数字顾问 -> 购买资料/对话许可或加入顾问席位 -> 提交交易意向”。短期付费点成立，长期交易转化也有入口。

建议：
- 把会员定义稳定为“买方企业服务包”，不要把会员直接叫成“数字人会员”。
- 把顾问席位定义为“可长期保存并继续咨询的数字顾问入口”，只由专业版/企业版提供。
- 把资料/对话许可定义为“某个付费专利的深度问答和资料摘要权限”，购买后自动获得该专利顾问。
- 搜索页只展示 Top 5，并把推荐理由留在卡片内，避免分页和过多入口分散企业决策。
- 用户中心继续保持三个核心入口：需求项目、数字顾问、交易意向；其他内容尽量收纳在二级区域。

## Next Iteration Notes
- 可以在用户中心增加一行极短说明：“会员提供服务能力，许可解锁单项专利深聊，顾问席位用于长期跟进。”
- 交易意向后续需要“待跟进、已联系、商务评估中、已关闭”等状态，但不建议这轮展开。
- 真正上线前，LLM key 必须改为后端代理或短期 token。
