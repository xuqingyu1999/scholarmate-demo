# ScholarMate 会员顾问席位与推荐质量再修正

## Goal

把买方企业会员权益重新表达清楚：会员服务包同时限制技术需求项目数、长期数字顾问席位数、Token 和资料/对话许可权益。免费认证版可以试用和创建少量需求，但不拥有长期顾问席位。专业版/企业版才是购买顾问席位的付费会员。

同步修正推荐算法：不能因为免费共享、已购许可或会员可访问而把低相关专利顶进 Top 5。商业加权只能在需求相关性达标以后生效。

## Acceptance Criteria

- 用户中心、会员页、聊天页都清楚显示“需求项目”和“顾问席位”是两个不同权益。
- 免费认证版顾问席位为 0；专业版/企业版显示可加入的长期顾问席位。
- 加入数字顾问席位时使用统一的顾问席位上限，不再只看历史字段 `maxInventors`。
- 购买单项付费专利资料/对话许可仍可形成该专利顾问资产，但不等同于会员长期席位。
- 搜索“人工智能与医疗”时只返回医疗 AI/医疗隐私等强相关结果，不把工业、家居、冷链等泛 AI 或免费专利硬凑进 Top 5。
- 搜索“电池高温安全和热失控”时新能源电池热管理专利排第一。
- 搜索“隐私保护 医疗数据 上链”时医疗隐私/隐私上链相关专利优先。
- embedding 不可用时，本地规则仍按行业锚点、领域词覆盖和标题/摘要命中排序，并在低相关时少展示或提示上传完整需求文本。

## Implementation Notes

- 保留 localStorage key 和旧对象名，避免破坏既有演示数据。
- 可新增 `advisorSeatLimit` 作为清晰业务字段，并兼容旧 `maxInventors`。
- 推荐评分拆成基础相关性、行业/领域覆盖、商业加权三层；商业加权必须 gated。
- UI 文案保持轻量，避免把会员页做成复杂套餐说明书。

## Test Plan

- 添加或更新本地 Node 测试覆盖会员席位字段、免费版席位、付费版席位。
- 添加或更新推荐排序测试，覆盖医疗 AI、电池热失控、医疗隐私上链。
- 运行现有业务核心、需求上传、语义推荐相关测试。
- 进行一次浏览器 smoke，检查用户中心会员 CTA、会员页套餐、专利列表搜索结果。
