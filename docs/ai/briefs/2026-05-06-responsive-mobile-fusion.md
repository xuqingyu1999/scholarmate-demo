# ScholarMate 响应式手机版融合

## Summary
- 基于现有网页版做响应式手机版，不新增独立 mobile 站点。
- 手机端增加共享底部导航：首页、发现、需求、顾问、我的。
- 继续收敛业务文案：会员是买方企业服务包，顾问席位是长期咨询入口，资料/对话许可是单项专利深聊权限。

## Acceptance Criteria
- 共享脚本自动插入手机底部导航，桌面宽度隐藏。
- 底部导航 active 规则覆盖首页、发现、需求、顾问、我的。
- 搜索推荐仍只展示 Top 5，手机卡片不出现无效分页。
- 用户中心手机端单列显示，侧栏菜单变成横向滚动入口。
- 聊天页手机端优先保证输入区可用，不被底部导航遮挡。
- 不迁移旧手机版的补购席位、专利包、科研端逻辑。

## Verification
- Node 行为测试覆盖底部导航 active 规则。
- HTML inline script parse 与核心脚本 `node --check`。
- Browser smoke 覆盖 375px 和 430px 手机宽度的底部导航、搜索 Top 5、用户中心 hash、聊天输入区。
